# Kyodstack 브랜드

이 문서는 로고의 의미와 브랜드 사용 규칙을 한곳에 모은 기준 문서입니다. 기술 블로그의 소개 글, About 페이지, 브랜드 설명에 그대로 가져다 쓰는 것을 목표로 합니다.
기술 결정(토큰, 생성 스크립트, 아이콘 규칙)은 [ADR 0045](decisions/0045-brand-logo-and-colors.md)에 있습니다.

- 원본 파일: `public/web-kyodstack-logo.png`
- 파생 에셋 생성: `node scripts/brand-assets.mjs`

## 심볼의 의미

### 심볼 구성
- **상단의 다이아몬드**
  - 아직 가공되지 않은 Raw Data, 곧 Data Block을 의미합니다.
  - 하나의 데이터 단위이자 레이어, 원재료처럼 보이도록 설계했습니다.
- **중앙의 밝은 V 형태**
  - 데이터를 받아들이고 정렬하는 Processing / Transformation Layer입니다.
  - 여러 데이터가 하나의 구조로 모이는 모습이면서, 아래쪽 모루와 이어지는 Forge의 작업면을 은유합니다.
  - 모루를 직접 그리지 않고, 데이터 레이어처럼 보이도록 추상화했습니다.
- **아래의 큰 양쪽 파츠**
  - 이 심볼에서 모루(Anvil) 역할을 하는 핵심입니다.
  - 넓고 무거운 형태로 Stability, Reliability, Engineering Foundation을 표현합니다.
  - `< >` 기호처럼, 또는 데이터가 중앙으로 모이는 구조처럼 보여 소프트웨어·데이터 엔지니어링의 느낌도 남깁니다.
- **중앙의 세로 Core**
  - 원재료가 시스템으로 변환되는 Data Flow / Engineering Pipeline입니다.
  - 가운데 다이아몬드는 데이터가 그냥 지나가는 곳이 아니라, 가공·검증·정제되는 핵심 지점입니다.

### 전체 흐름

```
Raw Data → Structure → Engineering Core → Reliable System
```

이 로고의 핵심 메시지는 "데이터를 저장하는 사람"이 아니라, **흩어진 데이터를 가공하고 단련해 견고한 시스템으로 만드는 사람**입니다.

## 색

로고의 세 가지 색이 곧 프로젝트의 메인 컬러입니다(ADR 0045).

| 이름 | HEX | 심볼에서의 역할 | UI에서의 역할 |
|---|---|---|---|
| Brand Blue (`--brand`) | `#75b2c7` | 세로 Core: 데이터 흐름, 파이프라인 | 메인 컬러. 다크 테마의 버튼, 포커스, 활성 표시 |
| Ink (`--brand-ink`) | `#1b2029` | 다이아몬드와 모루: 원재료, 기반 | 라이트 테마의 버튼, 앱 테마 색 |
| Soft (`--brand-soft`) | `#dee8f2` | V 레이어: 정렬과 변환 | 은은한 강조 면 |

## 사용 규칙
- 로고 옆에는 이름(Kyod)을 함께 둡니다. 화면에서는 `LogoMark` 컴포넌트를 씁니다.
- 어두운 바탕에서는 Ink 부분을 밝게 바꾼 변형(`public/brand/logo-mark-on-dark.png`)을 씁니다. 두 가지 파란색은 바꾸지 않습니다.
- 흰 바탕에서 Brand Blue는 대비가 2.3:1에 그칩니다. 그래서 글자나 작은 컨트롤에는 쓰지 않습니다.
- 브랜드 색은 상태를 나타내는 색(성공, 경고, 계획 등)으로 쓰지 않습니다.
