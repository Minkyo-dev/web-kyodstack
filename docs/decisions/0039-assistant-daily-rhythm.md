# 0039 — Assistant P1: daily rhythm (morning brief, evening check-in)

- Status: accepted
- Date: 2026-10-02
- Spec: docs/superpowers/specs/2026-10-02-assistant-p1-daily-rhythm-design.md (umbrella:
  …-assistant-architecture.md)

## Context
The owner wants the planner to work as a personal assistant toward their changes and growth. P1 gives it a daily
rhythm. Each morning a card says what matters today. Each evening a check-in decides the next day's "one thing".

## Decisions
1. **The brief is computed, not stored.** `buildBrief` is pure and runs on every scheduler load from live data.
   Only the AI coach line is cached (`assistant_briefs`, one row per user per local day), because it is the only
   part that cannot be recomputed.
2. **The one thing is picked by fixed rules, in order:**
   1. yesterday's chosen task;
   2. a task linked to an active 변화 and scheduled today;
   3. the earliest scheduled task;
   4. a task due today or overdue;
   5. the highest-priority task.

   The LLM never chooses it.
3. **The coach line is optional and lazy.** It is generated by `after()` once the page has responded, when today's
   row is missing. There are at most 3 attempts per local day (`ai_calls` kind `brief_line`), all inside the
   normal 30-call budget. A line containing a `DENY_LIST` word is dropped, so nothing is shown that day.
4. **The check-in extends `daily_reflections`** with `win`, `blocker` (6 fixed keys) and `next_task_id`. The
   composite FK `(next_task_id, user_id)` stops the row from pointing at another user's task. `on delete set null
   (next_task_id)` keeps the reflection when its task is deleted.
5. **Phases come from the local hour.** Before 12:00 it is the morning, from 12:00 to `evening_hour` it is the day,
   and from `evening_hour` on it is the evening. `scheduler_settings.evening_hour` defaults to 18 and has no UI yet.
6. **Missed-yesterday wording** names the habits and says "오늘 하면 두 번 연속은 아닙니다". It never shows a miss
   count.

## Consequences
- The scheduler page makes 4 more small reads: yesterday's reflection, yesterday's checks, the next 변화 step and
  the cached line.
- The first load of the day has no coach line. It appears on the next load.
